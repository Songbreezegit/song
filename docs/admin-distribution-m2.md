# 内容分发 M2 平台稿工作区

## 从内容源准备平台稿

在内容库打开已保存的内容源，选择「平台版本」。当前目标按账号列出，每个账号各有一份稿件。同平台的个人账号和项目账号分别生成、编辑和保存。首次生成使用服务器上已保存的标题、正文、标签、内容类型与素材顺序，状态从草稿开始。

平台稿编辑页可切换账号，编辑独立文案和标签，从现有媒体库选取素材，调整顺序并指定一张图片为封面。比例和处理说明随平台稿保存，供人工处理原始文件时参考。规则面板显示工作区检查、已确认规则、建议和待确认事项。预览使用当前表单，复制标题、正文、标签、全文以及 JSON 导出均取同一份已保存的稿件版本。

已移除的目标保留历史稿，重新选择该账号后可继续编辑原稿。账号停用时稿件只读，重新启用可恢复编辑。归档账号仍遵守 M1 的归档限制。账号更换平台后，历史稿保留原平台快照并只读。删除 M1 源草稿会一并删除其平台稿与关联，确认框提示影响范围。

## 版本和同步

- `distribution_variants` 通过 `(post_id, account_id)` 唯一标识当前平台稿。平台稿有独立的 `version`。`source_version` 记录最后完成核对的源版本，`source_snapshot` 保存每个字段最后核对过的源值。
- 内容源保存后，平台稿保留自己的内容。打开平台稿或刷新内容源时，差异面板并列展示上次核对的源值、当前源值和已保存稿件值。标题与正文同时变化时，可先同步正文，再同步同一源版本的标题。只有所有差异处理完毕，`source_version` 才推进。
- 勾选字段后可同步源值，也可明确保留平台稿的值。同步只更新选中的内容字段，仍被引用的媒体保留封面、比例和处理说明。保留决策记录在 `source_retained_fields`，字段再次变化时会显示新的差异。之后采纳该字段会清除它上一次的保留标记。
- 推广目标、项目关联或状态等变更未产生内容差异时，编辑器显示「仅源版本变化」。点击「确认版本变化」只更新核对进度和稿件修订元数据，平台稿内容与状态维持当前值。
- 同步、保留和确认都检查内容源与平台稿两个版本。待发布稿件仍须满足原有就绪校验，无法通过时整笔变更回滚。失败时保留编辑器和勾选项，保存与核对共用请求锁和离开保护。首次读取失败可重试。

## 平台规则来源

规则统一登记在 [registry.ts](../src/admin/features/distribution/platforms/registry.ts)，核对日期为 2026-11-10。工作区每稿最多引用 20 项素材，标题和正文的存储上限分别为 200 和 100,000 字符。平台图文、视频、文章和动态的呈现能力供本地预览与提示使用。

| 平台 | 核对范围及采用方式 |
| --- | --- |
| 小红书 | 笔记准备建议。图片数量、账号权益等以投稿入口为准。[开放平台](https://open.xiaohongshu.com/) |
| 抖音 | 参考视频和图文开放能力。封面和竖屏比例为准备建议。[抖音开放平台](https://developer.open-douyin.com/) |
| 哔哩哔哩 | 按视频、动态或文章准备。分区、数量和封面规格在投稿时核对。[创作中心](https://member.bilibili.com/) |
| 微信公众号 | 草稿接口作为入口参考。人工发文时复核账号类型和排版。[草稿接口](https://developers.weixin.qq.com/doc/offiaccount/Draft_Box/Add_draft.html) |
| 微博 | 参考分享入口。人工发文长度、数量和话题格式待核对。[分享接口](https://open.weibo.com/wiki/2/statuses/share) |
| 知乎 | 参考文章、想法和视频等形态。专栏和普通创作的入口有差异。[创作者手册](https://www.zhihu.com/knowledge-plan/manual) |
| X | 常规帖与订阅长帖规则不同。校验提示在实际账号上确认。[帖子类型](https://help.x.com/en/using-x/types-of-posts) |
| YouTube | 确认 Studio 视频标题最多 100 字符，说明最多 5,000 字符，标记待发布时检查。缩略图建议区分普通视频与 Shorts。[视频设置](https://support.google.com/youtube/answer/57404) · [缩略图指南](https://support.google.com/youtube/answer/72431) |
| 其他 | 通用标题、正文、标签和媒体预览。 |

界面将结果分为 `error`、`warning`、`info`，并标出规则可信度。标记待发布时，文章需要正文、图文需要图片、视频需要视频，动态需要正文或图片、视频中的一种。现有后台媒体库以图片为主，缺视频时可保存、预览及导出草稿，提示仍需准备视频。待发布表示本地准备完成，实际投稿资格和账号限制由对应平台确定。

## M3 接入点

M2 的 `DistributionPreparationAdapter` 处理本地规则检查。M3 可以基于已保存的 `variant_id`、`variant_version` 和账号快照记录计划或人工发布确认。真实平台适配器、OAuth、凭据存储、队列与回执应放在独立的服务端授权边界。计划和执行历史应独立记录，保留计划所对应的稿件版本。详见 [安全与 Staging 验收](admin-distribution-m2-security.md)。
